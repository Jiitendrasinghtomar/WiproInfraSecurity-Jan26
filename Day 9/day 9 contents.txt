file sharing
---------------
1. Samba share
	- for sharing data between different OS
		L <--> W
		L <--> L
	- mostly used by cloud for sharing the data.
	- cloud uses SMB4.0 protocol to share the data.
		SMB = Service Message Block
	- once available, it looks like a local hard drive (disk)

2. NFS share
	- for sharing data between similar OS
		L <--> L
		W <--> W

Backup
---------
1. Full backup
	- it captures all the copies of the backup.
	- for the 1st time, full backup will be taken.
	
2. Incremental backup
	- it copies only data changed since last backup.
	- it can be used for backing up data on regular intervals.
	
3. Differential backup
	- it copies all data changed since last "FULL" backup.

Palo-Alto Firewall
------------------
	- its a Next-Generation Firewall (NGFW)
	- it has advanced features like:
		- Deep packet inspection
		- IDS/IPS
		- DDOS protection
		- Application-level inspection
		- user identification
		- web content filtering
	- it helps in real-time content scanning.
	- it supports 
		- spyware protection
		- data-leakage
		- application vulnerabilities
	- 3 main features of PA-FW
		- App-ID 		- identify the application
		- Content-ID 	- scans the content
		- User-ID		- identify the user
