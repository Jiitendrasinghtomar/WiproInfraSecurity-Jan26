Network investigation
-----------------------
	- using wireshark

		- identify SYN scans
		
Host investigation
-----------------------
On windows
	- Sysmon
		- install manually from the MS website
		- Log source: "Microsoft-Windows-Sysmon/Operational"
	- Eventlogs
		- to fetch the events of sysmon
			Event viewer -> Applications and service logs -> Microsoft -> Windows -> Sysmon
			
For apache logs in Centos:
	access logs -> /var/log/httpd/access.log
	error  logs -> /var/log/httpd/error.log
