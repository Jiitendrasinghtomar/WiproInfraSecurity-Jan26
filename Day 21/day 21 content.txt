Archive 
	- combining multiple files and folder together.
	- similar to ZIP in windows
	- this does not reduce the file size.
	- we use the tool -> tar
	cmd
		create a tar - # tar  -cvf  file.tar file1 file2 ...
		extract tar  - # tar  -xvf  file.tar
	
Compression
	- reducing the actual file size 
	- we have tools like:
		- GZIP	- slow in nature, but compresses high data
		- BZIP2	- faster in nature, but compresses low data
