SELinux
	- Security Enhanced Linux
	- default its always "Enforcing"
	- modes
		- Enforcing 	- 100% active
		- Permissive 	- partial active
		- Disabled		- 100% inactive
	- commands
		# getenforce	//list the SELinux mode
		# setenforce	//set/changes the mode
		# sestatus		//displays SELinux status

Multi-User Hierarchical File System :
==============
/
	- /bin		= command binaries of regular users
	- /sbin		= command binaries of ROOT user
	- /home		= home directory of regular user
					- /home/chirag
					- /home/tanu
	- /root		= home directory of ROOT user.
	- /etc		= contains the configuration files
	- /var		= contains LOG files in it.
	- /tmp		= contains temporary files, that can be deleted anytime.
	- /dev		= contains all the device related file in it.
	- /mnt		= mount point, where devices are mounted and accessed. (old)
	- /run		= similar to /mnt, but nowadays all systems use /run. (new)
	- /usr		= contains users installed applications
	- /opt		= legacy support for /usr
	- /lib		= for developers -> 32bit systems
		- /libx64	= for developers -> 64bit systems
	- /boot		= contains boot related files. (Minimum: 500MB)
	- /proc		= contains all the running processes in it.
	
	
	Pendrive (myPD) --> /dev/myPD (unreadable) --> /mnt/myPD (readable)
